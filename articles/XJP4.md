說真的，最初的研究就是一坨大的，基本上沒什麼有用的東西，最後也棄置了。

但這份研究卻延伸出了兩個東西。一個是我人生中第一個完整的實驗專案「CNN 的注意力模組比對」，它原本是最初研究的前置子實驗，用來決定最後要用哪個注意力模組（放在 ViT 裡的 CNN 部分）。另一個就是我現在的論文主題「Transformer 的歸一化層與梯度流研究」，它原本也是子實驗之一，用來實驗優化方案，最後被擴展成了一份完整的研究。

## 第一個完整實驗專案：CNN 的注意力模組比對

這個專案從五月開始，把 SE、CBAM、GCNet、SA-Net、GSOP、ECA-Net、ELA 這些注意力模組接到輕量 CNN 上做比較，原本的目的是替 MobileViT 挑出最適合的模組。

它最後停在一個完整的研究框架，沒有走到真正的結論，手上只有一堆實驗產出。但這個專案給我最大的收穫本來就不在結論，而是在搭框架的過程：怎麼建一個嚴謹的實驗框架？實驗要怎麼跑？結果要怎麼檢查？消融要怎麼做？這些問題我都是在這裡第一次認真面對，後來也全部帶進了下一個研究。

同時，在一個一個研讀注意力機制的過程中，我也意識到自己的數學能力還不夠。這件事後面還會再出現一次（嗚嗚嗚 又被嗆qwo）。

## Transformer 的歸一化層 與 梯度流研究

### 起點

這個研究是在高中畢業後、升大學前的暑假開始的（7/2），一樣沒有指導。它源自我在研究 MobileViT 時冒出的一個疑問：不同種類的 normalization，以及它放的位置（placement），到底會怎麼影響模型和梯度？

一開始我把它定位成「重現 + 視覺化」：讀幾篇論文，自己重現一遍，確認自己是不是真的懂了。第一版 README 我甚至直接寫了「這不是原創研究」。

第一版做了 12 種 normalization 配置 × 3 個任務。招牌發現是：Post-LN（LayerNorm 放在殘差相加之後，也就是原始 Transformer 的寫法）在 16 層、不加 warmup 的設定下完全訓練不起來，但 AdaIN-local、SPADE 這類 conditional normalization 可以「逃脫」（loss 從隨機水準掉下來，真的學會任務）。我當時的解釋是：它們提供了一條繞過 normalization、讓梯度直接往回傳的捷徑（backward gradient bypass），證據是這條路的梯度佔比，在 loss 驟降的同一刻從 0 升到 0.98。

看起來很完美，對吧？

### 第一次被推翻

7/31 的第一次審查，以 workshop 論文的標準給了 3.0/10（Reject），以無指導的自學專案則是 8.0/10。12 項問題裡有 11 項成立，其中最致命的一項直接打在我的招牌結論上：把那條 bypass 切斷（detach）之後，AdaIN-local 照樣逃脫。

8/8 我自己用 15 個 seeds 重做：切斷前 9/15，切斷後還是 9/15。我最引以為傲的結論，就這樣被推翻了。

那時候真的心驚肉跳，開始懷疑自己的正確性：我到底是不是走在正確的研究道路上？

之後我花了一個多禮拜，把整個專案從頭修一遍：第一次用 git、先把受審的數據凍結備份再重跑、每個階段打 tag……也在這過程中又推翻了自己一次：我把訓練中逐層梯度的崩塌完全擋住，模型卻還是一樣訓練不起來，代表那個崩塌只是伴隨現象，不是原因。

回頭看，這幾次被推翻的東西，形狀都一模一樣：相關性很強、機制說得通、時間點精確同步，但實際去干預，就是沒有因果。這大概是我整個研究學到最重要的一課。

8/16 我打算把這個專案擴寫成論文投 TAAI，於是又請 AI 以教授的角度做了第二次審查，這次專門審方法、推論和結論。結果好幾個論據又被指出超出了資料能支持的範圍，或只是指標選擇造成的假象。我又一次心驚肉跳。

### 走在前人的路上

「走在前人的路上」這件事，其實一直伴隨著我的研究過程。我從一開始就知道這是一條已經有很多人走過的路，過程中甚至想過乾脆中斷研究，因為怎麼做都發現自己在重走前人的路。

轉機是某次為了確保正確性而補做的實驗。它跑出了一些和預期不一樣的數值，有種不對勁的苗頭，於是我開始往那個方向追下去。結果發現：根本不需要 conditional normalization 那套乘性的 modulation，只要把 embedding 在每個 normalization 的位置加回去（re-injection），就能 15/15 救活 Post-LN；而把 backward 那條路切斷之後，依然是 15/15。

這最終形成了我這篇論文的主張。

但故事還沒完。後來我又發現，連這條我覺得最原創的線，都已經有近親文獻了（B2T Connection、DenseFormer、Admin）。雖然早有心理準備，還是不禁有點失望。人總是喜歡幻想自己很特別，能找到別人沒找到的東西吧。

不過把文獻定位補上之後，真正屬於我的那一小塊反而變清楚了：這些繞過 normalization 的連接，為什麼救得回訓練？是因為 forward 帶進來的資訊，還是 backward 給的梯度捷徑？還沒有研究把這兩個方向拆開來檢驗過。

### 最後的主張

之後我又補了幾個關鍵實驗：讓 re-injection 的模型在第 0 步和 Post-LN 逐位元相同（這樣兩者唯一的差別，就只剩那條連接）、把 embedding 裡的 token 內容和位置資訊拆開，再測試換 learning rate、換任務時結論還成不成立。最後收斂成這一句：

> 救活 Post-LN 的是 forward embedding re-injection；backward gradient bypass 有幫助，但不是必要條件。

在配對設計下，Post-LN 是 0/15，re-injection 是 15/15；切斷 backward 仍然是 15/15，只是逃脫得比較慢（backward 那條路大約能讓模型早 176–294 步逃脫）。而真正需要的是 token 的內容，只給位置訊號是 0/15。

## 尋找指導

前面說我「可以說沒有任何指導」，這篇研究確實是我自己一路做過來的，但在這過程中，有兩位教授給了我很重要的回饋。

找教授這件事，其實我拖了很久。入學前系主任就建議我可以主動聯絡做 AI 的教授，但我一直很怕：怕太冒昧、怕被無視、怕問的問題太基礎。參考朋友的信也沒什麼用，因為我們的經歷差太多了<sub>(還是那個佬 嗚嗚嗚 高三就發AAAI 怎麼比qwo)</sub>。寫信的過程總是擔憂這、擔憂那，甚至連自己到底想從中得到什麼都說不清楚。

最後我寄信給了現在高科資管的陳彥銘教授，教授邀請我去面談。面談時也聊到了當時還在進行中的這個研究：教授指出 README 裡 AI 術語的中英互譯常常出問題，從那之後我所有文件的 AI 術語都改用英文原文；教授也點出了我一些基礎能力上的問題，例如 Eq. 1 和 Jacobian 的部分。

另一位是我的大姨丈，他是雲科機械系的教授。在把論文交給實驗室教授之前，我先給他看過，他建議正文要一步一步帶讀者讀懂圖表，圖表的標題則可以簡化。

論文完成後，我交給陳彥銘教授檢視，教授的回覆是：

> 以參加研討會的角度是ok的，但是以純做實驗的文章，其實對你的幫助不大。

聽到前半句很開心，教授認可了這篇論文。但後半句也讓我想起面談時就被指出的那些基礎能力問題。我的理解是：這篇論文的結論，是靠大量實驗（換 seed、加對照組、設閘門）一點一點堆出來的，但背後的數學機制，我其實還沒有真正吃透。

雖然有點氣餒，但這也給了我之後需要補足的方向，和繼續往前的動力。

## 論文的撰寫過程

寫論文本身最難的，不是寫，而是抉擇。

研究做了快三個月，結果多到我應該能寫十幾頁，但 TAAI 高中生組只有 4 頁（還包含參考文獻）。你研究中的結果，哪些是好的？哪些是真正有貢獻的？你要怎麼證明？又要怎麼讓別人相信你說的？最後，要怎麼把所有重要的內容塞進 4 頁裡？

實際排版之後更殘酷：一開始用假文字實測，4 頁大概只放得下七百多字；把圖表放進去之後，正文一度只剩五百多字的空間，而每多一篇參考文獻就要吃掉大約 56 個字。最後參考文獻砍到 11 篇，很多做過的東西（梯度崩塌、char_lm 的資訊洩漏……）整條都沒寫進去。

至於「怎麼讓人相信」，我的做法是把實驗設計做到能直接檢驗：讓兩組模型在第 0 步逐位元相同、用配對的 McNemar 檢定，再寫腳本把論文裡的 34 個數字全部從原始資料重算一遍。

同時英文也是我的一大痛點，那是我從來沒好過的科目 qwo

另外留幾個給想投 TAAI 的人的小提醒：
- LNCS 範本預設的紙張是 Letter，要自己改成 A4 (什麼鬼 和溢位))。
- 4 頁寫滿之後，多一行字就可能把最後一篇參考文獻擠到第 5 頁，改稿時要一直盯著版面。
- 我投稿時已經高中畢業了(以應屆畢業生投稿)，所以有先向主辦方確認投稿資格。跟我一樣的人建議先確認。

最後，論文經過教授檢視後寄出，也順利收到了投稿確認。
